# Arc Reactor

> 쓸모없지만 화려하죠?

스크롤을 **멈추지 않아야** 차오르는 랜딩 페이지.
8초를 버티면 빛이 터져 화면을 덮었다가 걷히고, 진짜 페이지가 열린다.
손을 떼면 3초 만에 0으로 돌아간다.

## 동작

```
IDLE ──스크롤──▶ CHARGING ──p=1.0──▶ COMPLETE ──▶ 진짜 페이지
                   │  ▲
         입력 끊김 │  │ 다시 입력
                   ▼  │
                DECAYING ──p=0──▶ IDLE
```

### 열리는 순간

1. 중앙에서 흰빛이 터져 **화면을 꽉 덮는다** (약 0.6초)
2. 그 빛에 가려진 동안 리액터가 **뒤로 물러나 아래로 내려간다** (`uRecede`)
3. 빛이 걷히면서 페이지가 떠오른다

전환을 **보여주는** 게 아니라 **가려서** 매끄럽게 만든다 —
게임에서 로딩 중 화면을 한 번 덮는 것과 같은 수법이다.
페이지가 열린 뒤에는 스크롤이 브라우저로 되돌아가 평범한 페이지가 된다.

### 페이지 내용 바꾸기

`src/landing/Landing.tsx` 의 `SPECS` · `TEMPLATES` 와 히어로 글만 갈아끼우면 된다.
구조(히어로 → 제원 → 목록 → 바닥)는 다른 템플릿에도 그대로 쓴다.
공개 레포를 만들면 `REPO_URL` 에 주소를 넣는다 (null 이면 링크를 안 그린다).

- 페이지는 스크롤되지 않는다. 휠·터치·`Space`/`↓` 는 오직 **연료**로만 쓰인다
- **건너뛰는 문이 있다.** 오른쪽 위 버튼 또는 `Esc`. 이건 장식이 아니다 —
  8초 연속 스크롤을 못 하면(손목 통증·운동 장애·스크린 리더) 이 페이지의
  내용에 닿을 방법이 아예 없어진다. **농담이 접근성을 이기지 못한다.**
  이 템플릿을 복사해 갈 때 이 버튼을 지우지 마라
- 진행률은 `aria-live` 로 10% 단위로 읽어 준다 (60fps 로 갱신하면 읽기가 끊긴다)
- 롤백 도중 다시 굴리면 **떨어진 지점에서** 다시 올라간다
- `prefers-reduced-motion` 을 존중한다 — 화면 흔들림이 꺼진다

## 만지는 숫자

`src/reactor/useCharge.ts` 의 `TUNING`:

| | 기본값 | 뜻 |
|---|---|---|
| `chargeSeconds` | 8 | 계속 굴렸을 때 0 → 100% |
| `decaySeconds` | 3 | 손 떼면 현재 값 무관하게 0 까지 |
| `inputGraceMs` | 120 | 이 시간 입력이 없으면 "손 뗐다" |
| `wheelThreshold` | 1.5 | 트랙패드 관성 꼬리를 무시하는 최소 델타 |

`src/reactor/ArcReactor.tsx` 의 `MOTION`:

| | 기본값 | 뜻 |
|---|---|---|
| `maxShakePx` | 22 | 최대 충전일 때 카메라 흔들림 진폭 |
| `tiltAmount` | **0** | 마우스로 시점 기울이기. **0 이면 완전 고정**, 1 이면 최대 |
| `spinBoostDegPerSec` | 150 | 게이지 반짝임 최고 속도 |
| `pulseBoostHz` | 2.6 | 맥동 최고 속도 |

## 구조

```
src/
  styles/tokens.css          간격 눈금 · 색 역할 · 움직임
  reactor/
    useCharge.ts             시뮬레이션 — rAF 루프. 화면은 전혀 안 건드린다
    ArcReactor.tsx           루프 값을 유니폼으로 넘기고, 캔버스 위 글자를 얹는다
    reactor.module.css       껍데기만 (글자·버튼·완료 화면)
    gl/
      renderer.ts            WebGL 뼈대 — 풀스크린 삼각형 하나
      reactor.vert.glsl      통과만 시킨다
      reactor.frag.glsl      ★ 리액터 전체가 여기 있다
```

**리액터는 그림이 아니라 계산이다.** 화면을 덮는 삼각형 하나를 그리고,
모든 픽셀에서 카메라 광선을 쏴 거리장(SDF)을 따라 전진시켜 표면을 찾고
거기서 조명을 푼다. 유니티 셰이더랩의 `CGPROGRAM` 안쪽과 개념이 같다.

CSS 그라디언트로는 못 넘는 벽이 셋 있어서 이렇게 갔다:

| | 왜 필요한가 |
|---|---|
| 정반사 | 표면 각도에 따라 하이라이트가 **움직여야** 금속으로 보인다 |
| 프레넬 | 가장자리 반사가 강해야 "오려 붙인 스티커"를 벗어난다 |
| 시차 | 카메라가 흔들릴 때 앞뒤가 다르게 밀려야 깊이가 생긴다 |

**설계 한 줄:** 진행률은 React state 가 아니다. `useRef` + `requestAnimationFrame`
으로 굴리고 유니폼에 직접 쓴다. React state 는 국면(idle/charging/decaying/complete)뿐이다.

## 셰이더 안 구조

레퍼런스: 불 켜진 MK1 정면, 순수한 검정 배경.

| 반지름 (바깥 = 1.0) | 층 |
|---|---|
| 1.00 ~ 0.855 | 팔 끝 금속 페룰 캡 10 |
| 0.84 ~ 0.575 | **발광 코일 몸통 10** — 팔이 스스로 빛난다 |
| 0.565 ~ 0.395 | 유리질 크롬 링 + 바깥 가장자리 눈금 띠 |
| 0.405 ~ 0.33 | 안쪽 립 |
| 0.335 ~ 0 | 코어 — 가운데가 하얗게 날아간다 |
| z = -3.4 | 거의 검정인 뒷면 |

**팔이 바깥으로 튀어나오는 건 맞다.** 톱니로 보였던 건 팔이 어둡고 각졌기 때문이다.
빛나고 둥근 팔은 기어로 안 읽힌다. 대신 이 셋이 필요하다:

1. **팔 사이에 검은 틈이 보여야 한다** — 넓히면 하나의 흰 고리로 뭉친다 (반각 9.5°)
2. **감긴 줄무늬** — 균일한 빛 덩어리는 "빛나는 조각"이지 코일이 아니다
3. **끝 캡이 어두워야** 팔 끝으로 읽힌다

진행률은 두 겹 — 코일 10칸이 12시부터 하나씩 점화되고,
크롬 링 가장자리의 눈금 띠가 연속으로 차오른다.

## 조명 — 왜 이게 실물처럼 보이나

CSS 그라디언트에서 셰이더로 넘어온 것만으로는 부족했다.
"그림"과 "물건"을 가르는 건 이 다섯이다.

| | 하는 일 |
|---|---|
| **소프트박스 환경** | 금속은 자기 색이 없다. **비치는 것**이 곧 금속의 모습이다. 매끈한 그라디언트를 비추면 아무리 만져도 플라스틱이다. 가장자리가 뚜렷한 네모난 광원이 비쳐야 눈이 금속으로 읽는다 |
| **AO (주변 차폐)** | 틈새가 어두워진다 → 깊이. 레이마칭에선 법선 방향으로 5번 찔러 보면 끝 |
| **부드러운 그림자** | 팔이 링에 그림자를 드리운다 → 앞뒤 관계가 보인다 |
| **GGX 스펙큘러** | 하이라이트 모양이 거칠기에 맞게 변한다 |
| **재질별 F0** | 알루미늄 `0.91` · 크롬 `0.55` · 강철 `0.56` · 구리 `(0.95, 0.64, 0.54)`. 전부 회색으로 두면 알루미늄도 구리도 똑같아 보인다 |

거친 표면의 흐린 반사는 **반사 방향 둘레를 4번 더 찍어 평균**낸다.
반사 방향을 법선 쪽으로 당기기만 하면 흐려지는 게 아니라 **빗나간다**.

### 비용

AO 5회 + 그림자 24회 = 픽셀당 `map()` 호출이 약 30번 늘었다.
느리면 해상도를 낮춰라 — 콘솔에서 `__reactor.setScale(0.75)`.

## 색 테마

셰이더는 `--color-arc` / `--color-arc-hot` **두 개만** 읽는다.
`tokens.css` 의 팔레트 몇 줄만 바꾸면 리액터 전체 색이 바뀐다 — 셰이더는 안 건드린다.

| | |
|---|---|
| 기본 | 아크 블루 |
| `?theme=ember` | 용광로 (주황) |
| `?theme=toxic` | 방사능 (초록) |
| `?theme=violet` | 심야 (보라) |

새 테마는 `tokens.css` 에 `:root[data-theme='이름'] { ... }` 를 추가하면 끝이다.

## 튜닝

주소에 **`?charge=0.55`** 를 붙이면 그 값으로 고정된다 (개발 모드 전용).
연출을 손볼 때 8초씩 굴리고 있을 수 없어서 만들어 뒀다.

콘솔에서도 만질 수 있다:

```js
__reactor.set({ charge: 0.8, tiltX: -0.3 }); __reactor.draw()
__reactor.setScale(0.75)   // 느리면 해상도를 낮춘다 (기본 min(DPR, 1.5))
```

## 규칙

- 의존성 없다. React + WebGL만
- UI 라이브러리 안 쓴다. CSS Modules + CSS 변수만
- 간격 숫자는 `tokens.css` 의 눈금에서만 고른다 (한 칸 = 4px)
- 색은 역할로 쓴다 (`--color-arc`, `--color-void`)
