## 구조

각 폴더가 **독립된 Vite 앱**이다. 폴더 하나만 복사해 가도 그대로 돌아간다.

```
useless-but-shiny/
  arc-reactor/       ← 01
  flashlight/        ← 02
    package.json
    src/
  (다음 페이지)/
```

공용 코드를 억지로 뽑지 않는다. 페이지마다 재료가 달라서, 공유하려다
쓰지도 않는 추상화만 늘어난다. 대신 **디자인 토큰**(`src/styles/tokens.css`)은
같은 눈금을 복사해 쓴다 — 한 칸 = 4px.

## 실행

```bash
cd arc-reactor
npm install
npm run dev
```

## 만들 때 지키는 것

- **의존성 최소.** React 와 WebGL 뿐 — 3D 라이브러리도 셰이더 라이브러리도 안 쓴다
- **UI 라이브러리 없음.** CSS Modules + CSS 변수. 버튼 하나도 직접 만든다
- **간격은 눈금에서만.** `13px` 같은 값이 부품 CSS 에 직접 나오면 안 된다
- **색은 역할로.** `--color-arc` 는 되고 `#5ec8ff` 는 안 된다
- **`prefers-reduced-motion` 을 존중한다.** 화면 흔들림은 실제로 어지럼증을 일으킨다
