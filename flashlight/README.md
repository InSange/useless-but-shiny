# 어둠 속 손전등

화면이 캄캄하다. 커서가 손전등이다.
**비춘 자리는 잔상으로 남았다 몇 초 만에 사라진다.**
숨겨진 여덟 조각을 다 찾으면 불이 켜진다.

## 어떻게 만들어졌나

```
4  숫자판                     언제나 보인다
3  찾아낸 글  ★ 어둠 위        한 번 찾으면 다시 안 어두워진다
2  어둠 (WebGL 셰이더 한 장)   빛이 닿은 만큼만 뚫린다
1  아직 못 찾은 글 · 물건
0  벽
```

**3번이 규칙의 전부다.** 찾으면 어둠보다 위층에 서므로 영영 보인다.
못 찾은 것은 어둠 아래라 비출 때만 보이고, 지나가면 잊힌다.
"찾았다"를 색이나 글씨가 아니라 **층**으로 표현했다.

### 글은 처음부터 끝까지 진짜 HTML

어둠은 페이지를 그리지 않는다. 페이지 **위에 덮인 가림막**이고,
계산하는 것은 알파(얼마나 가릴지)뿐이다.
그래서 글자는 어둠에 가려 있어도 복사되고 검색되고 화면 낭독기가 읽는다.

### 그림자

픽셀마다 빛을 향해 걸어가며 물체를 얼마나 아슬아슬하게 스쳤는지 잰다.
닿았나/안 닿았나만 보면 경계가 칼로 자른 듯 딱딱해진다 — 종이 오려 붙인 것처럼.
스친 정도를 재면 반그림자가 생긴다. 물체에서 멀수록 넓게 번지는 것도 공짜로 따라온다.

### 기억

88칸짜리 격자에 빛이 닿은 세기를 적어 두고 2.6초마다 절반씩 지운다.
격자는 CPU 에서 굴리고 텍스처로 올린다 — 값이 자바스크립트에도 있어야
"이 조각을 충분히 비췄나"를 판정할 수 있다.

## 들어오자마자 뭘 해야 하는지

처음엔 아무 설명 없이 캄캄한 화면만 띄웠다. **규칙을 모르면 게임이 아니라 그냥 검은 화면이다.**
그래서 시작 안내 카드를 어둠 **위층**에 띄운다 — 규칙을 빛으로 찾아 읽게 만들면 안 된다.
마우스를 처음 움직이면 사라진다. "닫기" 버튼을 두면 그 클릭이 군더더기다.

찾을 때마다 아래 오른쪽에 알림이 뜬다. 어둠 속에서 스쳐 읽은 글을 놓쳤을 수 있으므로
방금 찾은 조각을 한 번 더 보여 준다.

## 만들면서 걸린 것

**빛은 스스로 안 보인다.**
그림자까지 완벽히 계산해 놓고도 화면이 캄캄했다. 벽을 순수한 검정으로 뒀기 때문이다.
검은 벽은 밝게 비춰도 검다. 벽에 콘크리트 결을 준 뒤에야 빛의 웅덩이가 생겼다.

**블렌딩을 켜면 안 된다.**
`blendFunc(SRC_ALPHA, ONE_MINUS_SRC_ALPHA)` 는 색만이 아니라 알파에도 적용된다.
밝은 곳은 `As=0` 이라 `A = Ad` — 직전 프레임의 어둠이 그대로 남는다.
한 번 어두웠던 자리가 다시는 안 밝아졌다. 화면을 덮는 삼각형 한 장뿐이라 블렌딩 자체가 필요 없다.

**밝기를 프레임마다 적분하면 안 된다.**
`battery += (1-battery)*k` 는 프레임 수에 의존한다. 화면이 느리면 불이 영영 안 켜진다.
경과 시간으로 직접 구하면 몇 프레임이 돌든 0.6초 뒤엔 1이다.

**잡음의 주기는 화면 픽셀로 정한다.**
먼지 잡음을 34주기로 뒀더니 한 덩이가 24px 이 되어 화면이 얼룩덜룩해졌다.
(반대로 2px 밑으로 내려가면 이웃끼리 평균나서 그냥 회색이 된다.)

**animation-fill-mode: both 는 일반 선언을 이긴다.**
안내 카드에 `both` 를 걸어 뒀더니 애니메이션이 끝난 뒤에도 마지막 프레임을 붙잡아서,
`opacity: 0` 으로 숨기려 해도 통째로 무시됐다. 마우스를 움직여도 카드가 안 사라졌다.
끝난 뒤 손을 떼야 하는 애니메이션은 `backwards` 를 쓴다.

**숨긴 글을 UI 가 가리면 안 된다.**
알림을 위쪽 가운데에 뒀다가 조각 하나를 정통으로 가렸다. 방금 찾은 것을 알림이 가리는 꼴.

**같은 글을 두 곳에 적지 않는다.**
마무리 페이지의 목록을 손으로 베껴 뒀더니, 방 안의 글을 고치자 조용히 어긋났다.
이제 `SECRETS` 하나에서 뽑는다.

## 주소 옵션

| | |
|---|---|
| `?found=N` | N 개를 찾은 상태로 시작. 8 이면 마무리까지 건너뛴다 |
| `?dbg=1` | 손전등 좌표·감쇠·기억 격자를 화면에 띄운다 |
