# 어둠 속 손전등

화면이 캄캄하다. 커서가 손전등이다.
**비춘 자리는 잔상으로 남았다 몇 초 만에 사라진다.**
숨겨진 단서 여덟 개를 다 찾으면 불이 켜진다.

단서 하나하나가 **실제로 가 볼 수 있는 쓸모없고 아름다운 웹사이트**다.
어둠 속에 놓인 것은 수수께끼 한 줄이고, 찾으면 종이 카드가 정체를 밝힌다.

| | 수수께끼 | 정체 |
|---|---|---|
| 01 | 끝이 없는 그림 한 장 | [Zoomquilt](https://zoomquilt.org/) |
| 02 | 누군가 당신을 가리키고 있다 | [Pointer Pointer](https://pointerpointer.com/) |
| 03 | 내려갈수록 어두워진다 | [Deep Sea](https://neal.fun/deep-sea/) |
| 04 | 모래는 쌓이기만 한다 | [This Is Sand](https://thisissand.com/) |
| 05 | 지구 반대편의 라디오 | [Radio Garden](https://radio.garden/) |
| 06 | 이력서를 운전한다 | [Bruno Simon](https://bruno-simon.com/) |
| 07 | 아무 키나 눌러 보세요 | [Patatap](https://patatap.com/) |
| 08 | 다음은 어디든 | [The Useless Web](https://theuselessweb.com/) |

카드의 그림 여덟 장은 **SVG 로 직접 그렸다.** 남의 화면을 퍼오지 않아도 되고,
저장소에 그림 파일이 안 쌓이고, 여덟 장이 같은 손으로 그려져 톤이 맞는다.

## 어떻게 만들어졌나

```
4  숫자판                     언제나 보인다
3  찾아낸 글  ★ 어둠 위        한 번 찾으면 다시 안 어두워진다
2  어둠 (WebGL 셰이더 한 장)   빛이 닿은 만큼만 뚫린다
1  아직 못 찾은 글 · 물건
0  벽
```

**3번이 규칙의 전부다.** 찾으면 어둠보다 위층에 서므로 영영 보인다.
못 찾은 것은 어둠 아래라 비출 때만 보이고, 지나가면 잊힌다.
"찾았다"를 색이나 글씨가 아니라 **층**으로 표현했다.

### 글은 처음부터 끝까지 진짜 HTML

어둠은 페이지를 그리지 않는다. 페이지 **위에 덮인 가림막**이고,
계산하는 것은 알파(얼마나 가릴지)뿐이다.
그래서 글자는 어둠에 가려 있어도 복사되고 검색되고 화면 낭독기가 읽는다.

### 그림자

픽셀마다 빛을 향해 걸어가며 물체를 얼마나 아슬아슬하게 스쳤는지 잰다.
닿았나/안 닿았나만 보면 경계가 칼로 자른 듯 딱딱해진다 — 종이 오려 붙인 것처럼.
스친 정도를 재면 반그림자가 생긴다. 물체에서 멀수록 넓게 번지는 것도 공짜로 따라온다.

### 기억

88칸짜리 격자에 빛이 닿은 세기를 적어 두고 2.6초마다 절반씩 지운다.
격자는 CPU 에서 굴리고 텍스처로 올린다 — 값이 자바스크립트에도 있어야
"이 조각을 충분히 비췄나"를 판정할 수 있다.

## 들어오자마자 뭘 해야 하는지

처음엔 아무 설명 없이 캄캄한 화면만 띄웠다. **규칙을 모르면 게임이 아니라 그냥 검은 화면이다.**
그래서 안내를 어둠 **위층**에 띄운다 — 규칙을 빛으로 찾아 읽게 만들면 안 된다.
마우스를 처음 움직이면 사라진다. "닫기" 버튼을 두면 그 클릭이 군더더기다.

**상자로 만들지 않았다.** 테두리를 그으면 "방 위에 얹힌 UI"가 되어 방과 따로 논다.
대신 잉크가 번지듯 어둠에서 배어 나온다 — 가운데가 짙고 가장자리로 갈수록 흩어져
어디서 끝나는지 알 수 없게. 경계가 없으면 방의 일부로 보인다.
윤곽은 `feTurbulence` + `feDisplacementMap` 으로 들쭉날쭉하게 만들고 `blur()` 로 뭉갠다.

찾을 때마다 아래 오른쪽에 알림. 이것도 상자가 아니라 **튄 물감**이다
(데드 바이 데이라이트의 블러드웹 레벨 표시 같은 것).
한 번에 퍼지고 살짝 되튄 뒤 자리를 잡는다 — 천천히 커지면 물감이 아니라 풍선이다.

물감으로 보이게 하는 데 필요한 것은 셋이다.
**튄 방울**(작고 또렷하게, 거리를 섞어서), **고르지 않은 두께**(잡음 결을 겹쳐서),
**빠른 감쇠**(절반까지 꽉 찬 색이다가 바깥에서 급히 빠진다).
셋 중 하나만 빠져도 물감이 아니라 조명이 된다.

## 만들면서 걸린 것

**빛은 스스로 안 보인다.**
그림자까지 완벽히 계산해 놓고도 화면이 캄캄했다. 벽을 순수한 검정으로 뒀기 때문이다.
검은 벽은 밝게 비춰도 검다. 벽에 콘크리트 결을 준 뒤에야 빛의 웅덩이가 생겼다.

**블렌딩을 켜면 안 된다.**
`blendFunc(SRC_ALPHA, ONE_MINUS_SRC_ALPHA)` 는 색만이 아니라 알파에도 적용된다.
밝은 곳은 `As=0` 이라 `A = Ad` — 직전 프레임의 어둠이 그대로 남는다.
한 번 어두웠던 자리가 다시는 안 밝아졌다. 화면을 덮는 삼각형 한 장뿐이라 블렌딩 자체가 필요 없다.

**밝기를 프레임마다 적분하면 안 된다.**
`battery += (1-battery)*k` 는 프레임 수에 의존한다. 화면이 느리면 불이 영영 안 켜진다.
경과 시간으로 직접 구하면 몇 프레임이 돌든 0.6초 뒤엔 1이다.

**잡음의 주기는 화면 픽셀로 정한다.**
먼지 잡음을 34주기로 뒀더니 한 덩이가 24px 이 되어 화면이 얼룩덜룩해졌다.
(반대로 2px 밑으로 내려가면 이웃끼리 평균나서 그냥 회색이 된다.)

**animation-fill-mode: both 는 일반 선언을 이긴다.**
안내 카드에 `both` 를 걸어 뒀더니 애니메이션이 끝난 뒤에도 마지막 프레임을 붙잡아서,
`opacity: 0` 으로 숨기려 해도 통째로 무시됐다. 마우스를 움직여도 카드가 안 사라졌다.
끝난 뒤 손을 떼야 하는 애니메이션은 `backwards` 를 쓴다.

**숨긴 글을 UI 가 가리면 안 된다.**
알림을 위쪽 가운데에 뒀다가 조각 하나를 정통으로 가렸다. 방금 찾은 것을 알림이 가리는 꼴.

**같은 글을 두 곳에 적지 않는다.**
마무리 페이지의 목록을 손으로 베껴 뒀더니, 방 안의 글을 고치자 조용히 어긋났다.
이제 `SECRETS` 하나에서 뽑는다.

**SVG 필터의 기본 색공간은 linearRGB 다.**
잉크 얼룩 둘레에 자홍·노랑 테가 생겼다. 반투명한 가장자리에서 알파를 풀었다
다시 곱하는 과정에 색이 튄 것. `color-interpolation-filters="sRGB"` 로 못 박는다.

**번지는 것을 그라데이션 정지점으로 만들지 않는다.**
정지점을 애니메이션하면 매 프레임 그라데이션을 다시 칠하고 **변위 필터를 다시 돌린다**.
86만 픽셀 × 2초를, WebGL 방이 도는 옆에서. `scale` 은 필터를 한 번만 돌리고
그 결과를 GPU 가 확대한다. 얼룩이 커지며 결까지 커지는데 잉크와 오히려 맞다.

**경계가 구불구불한 것 ≠ 경계가 없는 것.**
감쇠 구간이 짧으면 변위 필터가 그 짧은 경계를 밀어내서 "물결 모양으로 오려 낸 것"이 된다.
정지점을 촘촘히, 끝까지 길게 끌어야 번진 것으로 보인다.
(물감은 반대다 — 거기서는 빨리 빠져야 덩어리로 보인다.)

**흐리게 하면 방울이 죽는다.**
물감에 `blur(3px)` 만 줬는데 튄 방울이 뭉개져 초록 안개가 됐다.
불규칙함은 흐림이 아니라 변위 필터가 만든다. 흐림은 1px 이면 충분하다.

**글자 색은 "무엇 위에 놓이는지"까지 보고 정한다.**
얼룩 위에 올라가는 글에 어두운 방 기준의 `--color-dim` 을 그대로 썼더니 안 읽혔다.

**한글은 `word-break: keep-all` 없이는 조판이 안 된다.**
기본값은 한글을 "어디서든 끊어도 되는 글자"로 봐서 '생물이'가 '생물' / '이' 로 갈라진다.
keep-all 은 띄어쓰기에서만 끊는다. 대신 긴 영문 주소가 넘칠 수 있어 그런 곳만 따로 푼다.

## 주소 옵션

| | |
|---|---|
| `?found=N` | N 개를 찾은 상태로 시작. 8 이면 마무리까지 건너뛴다 |
| `?clue=N` | N 번째 단서 카드를 바로 펼친다 |
| `?dbg=1` | 손전등 좌표·감쇠·기억 격자를 화면에 띄운다 |

## 실행

```bash
npm install
npm run dev
```
